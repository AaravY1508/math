# erich-friedman

Computational research harnesses for open problems from Erich Friedman's
[Packing Center](https://erich-friedman.github.io/packing/). Each problem lives
in its own self-contained folder with its own `requirements.txt`, virtualenv,
and `runs/` directory. There is no shared top-level package, so a new problem
is added as a sibling folder.

| Problem | Folder | Status |
|---|---|---|
| [Maximum Fence Area](https://erich-friedman.github.io/packing/fence/) | [`maximum-fence-area/`](maximum-fence-area/) | Harness built; first 6h GPU search run launched 2026-09-10 |
